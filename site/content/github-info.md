## Practical updates

- **Make changes reviewable:** work on a branch, open a pull request, and use the review conversation to agree on the change before merging.
- **Use automation deliberately:** start with a small GitHub Actions workflow, keep permissions narrow, and make the trigger and expected output obvious to the next maintainer.
- **Turn repeatable tasks into Copilot workflows:** browse the [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/) collection for patterns that can be adapted to a repository’s conventions.
- **Keep the guidance current:** use the [GitHub Blog](https://github.blog/latest/) for product and engineering context, and the [GitHub Changelog](https://github.blog/changelog/) for dated feature and platform updates.
